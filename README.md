# 🕊️ رحلة التسامح — تجربة VR تفاعلية غامرة

تجربة واقع افتراضي عربية تفاعلية عن **التسامح والانتقام**، تعمل من المتصفح مباشرة على **الجوال + الكمبيوتر + Meta Quest 3S**.

> "التسامح مو ضعف… هو قرار. جرّب تشوف أثره بنفسك."

---

## ✨ المميزات

- 🌍 **عالم VR ضخم** — حديقة بـ 200+ شجرة، نهر، معبد، شلال، حقل لافندر، فراشات + ظلام موحش بأنقاض، مرايا، عواصف
- 🎯 **شجرة قرارات بمستويين** — خياران رئيسيان × 1-2 خيارات فرعية = 3 نهايات مختلفة
- 🔊 **صوت مكاني ثلاثي الأبعاد (HRTF)** — كل صوت يجي من اتجاهه الحقيقي ويتغيّر مع حركة الرأس
- 🎙️ **نطق عربي حقيقي** — ملفات صوت بشرية + Web Speech TTS كاحتياط
- 👥 **شخصيات NPC تفاعلية** — حكيم، طفل، مسافر، أشباح يقولون جملاً عند الاقتراب
- 🌹 **عناصر تفاعلية** — اقطف ورود، اقرع جرس المعبد، حطّم مرايا، أطفئ شموع
- 🚶 **حركة حرة 360°** — Joystick على الشاشة + WASD + Quest controllers + teleport
- 👣 **خطوات مكانية** + موسيقى خلفية متكيّفة مع البيئة

---

## 🚀 التشغيل

```bash
# Python
python -m http.server 8080

# أو Node
npx serve .
```

ثم افتح:
- 💻 الكمبيوتر: `http://localhost:8080`
- 📱 الجوال (نفس الواي‌فاي): `http://[IP-الكمبيوتر]:8080`
- 🥽 Meta Quest 3S: نفس الرابط من متصفح Quest، ثم اضغط زر Enter VR

## 🔧 التخصيص السريع

### غيّر النصوص أو شجرة القرارات
كل شي في [`js/config.js`](js/config.js): الجمل، الاقتباسات، الألوان، أوصاف الخيارات.

### غيّر الألوان
[`css/variables.css`](css/variables.css):
```css
--forgive-primary: #22c55e;
--revenge-primary: #ef4444;
```

### أضف ملفات صوت بشرية
ضع تسجيلاتك في:
```
assets/voices/male/1.mp3   ← الجملة الأولى ذكر
assets/voices/male/2.mp3
assets/voices/male/3.mp3
assets/voices/female/1.mp3
assets/voices/female/2.mp3
assets/voices/female/3.mp3
assets/voices/closing.mp3
```
المشروع يكتشفها تلقائياً ويستخدم HRTF للصوت المكاني.

**مصادر مقترحة:** ElevenLabs (أفضل صوت عربي AI)، Fiverr، أو سجّل بنفسك.

## 🎨 التقنيات

- **A-Frame 1.5** — محرك VR
- **Three.js** (عبر A-Frame) — الرسم ثلاثي الأبعاد
- **Web Audio API** + `PannerNode` HRTF — الصوت المكاني
- **aframe-extras** + **aframe-blink-controls** — حركة Quest
- **Vanilla JS** — لا build step، لا dependencies

# تسجيلات الصوت البشري

ضع ملفات `.m4a` (AAC) هنا ليتم تشغيلها بدل الـ TTS.

## الملفات المطلوبة

| الملف | النص |
|---|---|
| `1.m4a` | واضح إنك ما تفكر قبل تتصرف… وهذا شي مزعج بصراحة. |
| `2.m4a` | كل مرة نفس الأسلوب، ما فيه أي تغيير. |
| `3.m4a` | أخطاءك صارت متوقعة… مو شيء جديد. |

|---|---|

| `revenge_equal.m4a` | رددت بالمثل. لكن… هل شفي الجرح فعلاً؟ |

### الخاتمة

## كيف تجيب صوت إنسان حقيقي؟

### الخيار 1: ElevenLabs (الأفضل والأسرع — صوت اصطناعي بجودة بشرية)
1. روح **https://elevenlabs.io** وسجل (مجاني 10,000 حرف/شهر)
2. اختر صوت عربي من المكتبة (ابحث "Arabic")
3. الصق كل جملة، ولّد، حمّل كـ MP3
4. سمّها بالأرقام أعلاه وحطّها في المجلدات

### الخيار 2: علّق صوتي بشري حقيقي (Fiverr / خمسات / مستقل)
- ميزانية: $5-30
- ابحث عن "علق صوتي عربي" أو "Arabic voice over"
- اطلب صوت ذكر **وصوت أنثى** بنفس النصوص أعلاه
- الصيغة: MP3, 44.1kHz mono

### الخيار 3: سجّل بنفسك
- استخدم **Audacity** (مجاني) أو تطبيق مذكرة صوتية في الجوال
- ميكروفون أيفون أو سماعة بميكروفون كافي
- صدّر MP3
- نصيحة: سجّل بنبرة منخفضة محبطة لتطابق المشهد

## مواصفات الملفات
- **الصيغة:** M4A / AAC
- **معدل العينة:** 44.1 kHz أو 48 kHz
- **معدل البت:** 128 kbps فأكثر
- **القنوات:** Mono (لأنها أصوات نقطية، الـ Stereo يضيع الفائدة)
- **المدة:** 3-6 ثوان لكل جملة
